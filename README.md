RESTCONF CRUD Capstone Project


Description

This project is a Network Management System (NMS) developed using Spring Boot and RESTCONF. It allows users to manage network devices and perform CRUD operations on device configurations. The repository also contains the project presentation (PPT) explaining the architecture, workflow, and implementation.

Features

Add network devices
View device details
Update device configurations
Delete device records
RESTCONF-based communication
Network Management Dashboard
Project Presentation (PPT)


Technologies Used

Java
Spring Boot
RESTCONF
NETCONF
Spring Security
JWT Authentication
MySQL
Maven
HTML
CSS
JavaScript

How to Run

Extract the project zip file
Open the project in Eclipse or IntelliJ IDEA
Configure MySQL database settings
Build the project using Maven
Run the Spring Boot application
Test APIs using Postman or browser


Output

Performs CRUD operations on network devices
Manages configurations using RESTCONF
Provides project explanation through PPT
